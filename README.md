# Quiz App

A simple, interactive quiz application built using **vanilla JavaScript** and **Tailwind CSS**.  
The app presents multiple-choice questions, provides instant feedback on answers, and displays the final score at the end of the quiz.

🔗 **Live Demo:** https://quiz-app-ten-xi-49.vercel.app/
📦 **Source Code:** https://github.com/rajarshi-29/quiz-app

---

## 🚀 Features

- Dynamic rendering of quiz questions and options
- Real-time answer validation with visual feedback
- Score tracking and final result summary
- Restart quiz functionality
- Responsive UI using Tailwind CSS
- Smooth fade-in animation for improved user experience

---

## 🛠️ Tech Stack

- **HTML5** – Semantic structure
- **CSS (Tailwind CSS)** – Styling and responsiveness
- **JavaScript (ES6+)** – Application logic and state handling
- **Deployment:** Vercel

---

## 🧠 Application Logic Overview

- Questions are stored as an array of objects containing:
  - Question text
  - Multiple choices
  - Correct answer
- JavaScript manages:
  - Current question index
  - User score
  - UI state transitions (start, next, result)
- DOM manipulation is used to:
  - Render questions dynamically
  - Handle user interactions
  - Update UI based on quiz progress
